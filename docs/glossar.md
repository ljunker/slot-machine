# Glossar

Verbindliche Begriffe für Oberfläche, Hilfetexte und Doku. Der Code und die API behalten ihre technischen Namen (zum Beispiel `slot`, `/slots`), in der Oberfläche erscheinen sie nicht.

| Begriff | Bedeutung | Nicht verwenden |
| --- | --- | --- |
| **Session** | Ein Programmpunkt: Vortrag, Workshop, Pause usw. Gilt für eingeplante und ungeplante Sessions gleichermaßen. | Slot, Programmpunkt |
| **Ungeplante Session** | Session ohne Tag, Raum und Uhrzeit; liegt in der Seitenleiste, bis sie eingeplant wird. | Backlog (nur intern) |
| **Gemeinsame Session** | Session mit Geltungsbereich **Alle Räume**, z. B. eine Pause. | Shared Slot |
| **Zeitfenster** | Nur, wenn wirklich die Zeitspanne gemeint ist (Beginn bis Ende), nicht der Programmpunkt. | Slot |
| **Tag** / **Veranstaltungstag** | Ein Tag der Veranstaltung mit Beginn und Ende. | |
| **Raum** | Ort, an dem Sessions stattfinden. | Location, Track |
| **Kategorie** | Farbige Einordnung einer Session, z. B. „Workshop“. | Tag (wegen Verwechslung mit dem Veranstaltungstag) |
| **Redner** / **Rednerprofil** | Person, die eine Session hält, mit Foto, Kurzbeschreibung und Website. | Speaker |
| **Dienst** | Aufgabe für Helfer: allgemeiner Dienst, Raumdienst oder Session-Dienst. | Schicht, Duty |
| **Helfer** | Teammitglied, das sich in Dienste einträgt. | |
| **Tagesplan** / **Helferplan** | Planungsansicht mit Fokus auf Programm bzw. Dienste. | |
| **Besucherprogramm** | Öffentliche Programmseite für Besucher. | Public-Seite |
| **Änderungsmarkierung** | Hinweis **Verschoben** oder **Geändert** an einer Session nach der Veröffentlichung. **Abgesagt** ist ein Status, keine Markierung. | Änderungs-Flag, Flag |
| **Sicherung** | ZIP-Datei mit allen Daten und Bildern einer Veranstaltung. | Backup |
| **Sicherung wiederherstellen** | Eine Sicherung als neue Veranstaltung einspielen oder eine bestehende damit ersetzen. | Restore |
| **Veranstaltungsadmin**, **Bearbeiter**, **Helfer** | Rollen innerhalb einer Veranstaltung. | |
| **Superadmin** | Rolle mit Zugriff auf alle Veranstaltungen und Benutzer. Bleibt als feststehender Rollenname erhalten. | |
